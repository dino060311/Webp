## 📌 About Project

> Webp 저장소는 이미지 용량 감소 및 최적화를 위해 WebP 포맷 변환 알고리즘과 변환 옵션을 학습하고 구현한 프로젝트입니다.

### 🎯 Main Objectives

- PNG, JPG 등 기존 이미지의 WebP 포맷 변환 구현
- 이미지 품질($Quality$)과 압축률 간의 균형 최적화
- 배치(Batch) 처리 기능을 통한 다중 이미지 자동 변환
- 웹 환경에 최적화된 이미지 리소스 생성 및 성능 개선
